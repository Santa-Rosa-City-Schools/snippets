Snippets
========

This is a collection of Aeries queries that we share with staff.

The live website is available at https://santa-rosa-city-schools.github.io/snippets/

Contributing
------------

You can contribute a snippet by creating an issue using the "Suggest a Snippet" template. 
The form will ask you to provide all required information for a new snippet. 
Alternatively, you can use the "Suggest a Snippet" button on the live website.
