This editor is a local staging tool only — it never talks to GitHub directly, and app/snippets.json is no longer the source of truth. Each snippet now lives as its own markdown file under snippet/<category>/ (with the id, title, category, tags, and createdAt as frontmatter), and snippets.json is generated from those files at deploy time by scripts/build_snippets_json.py. Use the JSON below as a reference for the data when writing or updating a .md file, then commit that file via git. To request a new snippet without repo access, use Suggest a Snippet on the main library page instead.
