Has 504 Plan or 504 Program - This query will give you any student with a 504 Plan or a 504 Program. Review as needed.

```text
LIST STU SC? ID LN FN 504_PLAN 504_PRG BY STU.SC IF 504_PLAN =YES OR 504_PRG = YES
```
