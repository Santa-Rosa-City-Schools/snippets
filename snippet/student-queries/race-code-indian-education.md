Race code - Indian Education (If Race marked 100 and Ethncity Indicator not 'Y')

```text
LIST STU STU.ID STU.LN STU.FN STU.SC? STU.GR? STU.RC1? STU.RC2? STU.RC3? STU.RC4? STU.RC5? IF STU.ETH = N AND ( STU.RC1 = 100 OR STU.RC2 = 100 OR STU.RC3 = 100 OR STU.RC4 = 100 OR STU.RC5 = 100  )  
```
