Display immunization exemption values - It would be easier to run it as Excel so that you can filter for IMM.E1, IMM.E2 and IMM.E3. Remember that E1 is Permanent Exemption, E2 is Temporary Exemption and E3 is Personal Belief Exemption. A value will also display under any Immunization missing if there is a exemption reason. -

```text
LIST STU IMM STU.NM STU.ID LOC.NM STU.GR IMM.PE IMM.DE IMM.AE IMM.YE IMM.IE IMM.HAE IMM.VE IMM.TE IMM.TBE IMM.MCE IMM.PCE IMM.CVE IMM.CVD IMM.CVC IMM.E1 IMM.E2 IMM.E3
```
