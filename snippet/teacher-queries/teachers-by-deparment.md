Teachers by Deparment - This query will provide teachers in a given department. Change school code and department call as needed.

```text
 LIST SSE STF MST CRS LOC LOC.SNM STF.LN STF.FN STF.EM CRS.DC? MST.SC? IF MST.SC < 50 AND ( CRS.DC = "P" OR CRS.DC = "M" )
```
