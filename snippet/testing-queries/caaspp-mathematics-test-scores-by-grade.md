Math scores by grade level. Replace the X with the grade level the assessment was given (3rd graders tested in 2023-24 are now 4th graders, etc.).

```text
LIST STU TST CTL STU.ID STU.LN STU.FN STU.MN STU.SC? STU.GR TST.ID TST.TA TST.TD CTL.NM TST.SS TST.PL IF TST.TA = SPRG22 AND TST.ID = "SBAC" AND TST.PT = 2 AND STU.GR = X
```
