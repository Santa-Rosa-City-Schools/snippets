Secondary Teacher List  - Used for creating TOMS accounts for testing

```text
LIST SSE STF MST CRS LOC LOC.SNM STF.LN STF.FN STF.EM MST.CN CRS.DC? IF CRS.DC = "E" OR CRS.DC = "M" OR CRS.DC = "K"
```
