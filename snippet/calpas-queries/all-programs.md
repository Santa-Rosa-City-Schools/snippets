All Programs - Will list all student programs and includes local school ID, program ID, and program name.

```text
LIST STU PGM LOC STU.SC? STU.ID STU.GR STU.FN STU.LN PGM.PSD PGM.PED PGM.ESD PGM.EED PGM.CD PGM.CD? IF PGM.CD > ""
```
